# 本地安装包

当前：`dsh-zotero-research-1.0.0-beta.3.tgz`。

```sh
dsh plugin --profile <profile> add /absolute/path/dsh-zotero-research-1.0.0-beta.3.tgz
```

正常退出并重开 Harness。旧包升级前请按根目录 README 的 Upgrade 操作；保留 `storages/zotero-plugin`。macOS Apple Silicon 已验证，Windows/Linux 未实测。没有公开 npm 发布。

`dsh-zotero-1.0.0-beta.2.tgz` 仅作旧包兼容留存，不应与新包同时启用。
