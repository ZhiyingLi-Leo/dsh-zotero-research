# 安装包 / Installer

当前：`dsh-zotero-research-1.0.0-beta.3.tgz`。

```sh
dsh plugin --profile <profile> add /absolute/path/dsh-zotero-research-1.0.0-beta.3.tgz
```

正常退出并重开 Harness。升级、迁移与平台能力见 [安装指南](../docs/GETTING_STARTED.md)；保留 `storages/zotero-plugin`。

Install into the profile you use, then restart Harness. See the installation guide for upgrades, migration, and platform capabilities.

`dsh-zotero-1.0.0-beta.2.tgz` 仅供旧包迁移参考，不应与新包同时启用。
